# 3D artwork attribution

- **Iron-Man Mark 85 | Rigged** by [9A Films / Nihar Arora](https://sketchfab.com/Nihar-9Afilms), based on the original model by [LLIypuk](https://sketchfab.com/LLIypuk). [Source model](https://sketchfab.com/3d-models/iron-man-mark-85-rigged-dde1085c464d4f8da259fe6669ae4dd2), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Geometry and 66-bone Mixamo rig preserved during lossless meshoptimizer compression. Thirteen source maps resized to 1024/2048 px and converted to WebP. Website lighting, procedural flight articulation, and engine effects added. No bundled animation clips.

  The active flyby uses `ironman-mark85-flight.glb` (14.4 MB), with the same 639,859 triangles, skeleton, and materials. It uses 16-bit exponential float precision, more efficient triangle encoding, and 1024 px color/normal plus 512 px material maps. The earlier 29.7 MB model remains available locally. Verified bind-pose bounds are stored in the flyby file to avoid scanning every skinned vertex at startup.

- **Iron Man MK7** by [CHANG747](https://sketchfab.com/CHANGP453), [original model](https://sketchfab.com/3d-models/iron-man-mk7-ad4776eea8184283a3e49cf5487df754), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Web-optimized file from Tilak Patel's public model collection. Textures and mesh unchanged here; portfolio lighting and rigid-body movement added.
- **Millennium Falcon** by [Johnson Martin](https://sketchfab.com/Johnson-Martin), [original model](https://sketchfab.com/models/bd3e54ac20ff4ade8ddd8043db75c1d1), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The adapted model is distributed with [explicit credit by Flightradar24](https://github.com/Flightradar24/fr24-3d-models#license). Converted from glTF 1 to glTF 2, losslessly compressed with meshoptimizer, and given PBR versions of its five original gray materials. Original geometry and normals retained. There are no source texture maps.

The Falcon and previous compact MK7 contain no skeletal animation. Mark 85 has a real Mixamo rig used for procedural flight articulation; no source asset includes a bundled animation clip.

The exact **Iron Man Mark-7(Subsurf)** reference by [benjamin.borromeo](https://sketchfab.com/3d-models/iron-man-mark-7subsurf-a13c067e70814dc7b2ebc3f0ace10961) is a different model. Its authenticated download was not used. The portfolio instead uses the licensed Mark 85 model above for flight; the docking-bay viewer is reserved for the Falcon.
